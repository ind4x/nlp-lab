# Coursework resources and reference materials

This directory stores reference materials, assignment problem statements, and
foundational exercises associated with the Artificial Intelligence and Machine
Learning curriculum.

## Directory contents

- [Exercice_Regression_Descente_Gradient.pdf](./Exercice_Regression_Descente_Gradient.pdf):
  Technical problem statement on multiple linear regression optimized via
  gradient descent. Focuses on predicting academic outcomes using behavioral
  features (weekly study hours, attendance rates, sleep duration, and historical grades).
- [ex1.png](./ex1.png):
  Reference problem specification detailing manual gradient descent steps,
  weight initialization ($w=0, b=0$), learning rate scheduling, and Mean Squared
  Error (MSE) updates across discrete iterations.
